02 / MODULE MAP

先按責任找檔案。

src/main.ts

瀏覽器入口

只啟動 UI，不保存帳密、不處理遊戲協定。

src/ui/

介面與版面

app.ts 訂閱快照、管理分頁；activity-dialog.ts 獨立管理互動面板與 BC 部位熱區，不載入人物貼圖；style.css 管理手機版面。其餘頁面仍集中於 LiteApp。

src/network/

唯一的 Socket 擁有者

client.ts：登入、重連、房間、好友、私聊、召喚授權與送出驗證。模組重排不改變協定行為。

src/action/

動作與文字管線

catalog.ts 載入基底／差異；embedded.ts 讀取插件原文；render.ts 代入字典。labels.ts 統一標籤與身體別名；native.ts 判定原生活動；extensions.ts 管理擴展文字互動。cuddle.ts 集中 ECHO 貼貼條件與配對資料，不載入插件程式。

src/translations/ + src/i18n/

資料與翻譯函數分離

翻譯者編輯 JSON；i18n/index.ts 管理 UI 語言、參數及狀態重譯。不呼叫外部翻譯服務。

src/profile/ · media/ · safety/ · platform/

邊界功能

AFC／BIO、媒體來源許可、安全詞外觀規則、行動裝置連線輔助分開維護。shared/types.ts 定義共用資料。

03 / ACTION PIPELINE

擴充文字，不擴大執行權限。

  1. 接收與過濾network/client 接收 BC 封包，排除 Hidden／Status 等控制訊息，補齊玩家字典。
  2. 選取句子action/embedded 優先保留合規的封包附帶原文；沒有原文才使用文字表，最後退回通用文案或原始鍵。
  3. 字典代入action/render 解析角色、Asset／Group、CraftName 與 FocusAssetGroup，純文字替換，不執行插件程式。
  4. 呈現UI 以 textContent 建立訊息，再經媒體許可機制處理網址。原文聊天、BIO、房名不自動翻譯。
插件封包自带的原文目前優先於靜態翻譯，因此為了保留動態內容，有些插件訊息不會隨 UI 語言切換。新增動作資料不等於新增活動效果或原生互動引擎。

04 / TRANSLATION CONTRIBUTIONS

英文基底一次維護，其他語言只寫差異。

src/translations/
├─ ui/                     # 介面文字，en.json / zh.json
├─ bc/                     # 每類皆為 en 基底、zh 差異
│  ├─ messages/            # 系統與介面訊息
│  ├─ actions/             # 動作句子
│  ├─ items/               # Asset.部位.物品
│  └─ groups/              # Group.部位
├─ action/
│  ├─ xiaosu/              # 小酥動作
│  ├─ lscg/                # 英文原文；無翻譯時 zh 為空
│  └─ echo/                # ECHO 活動文字
├─ items/echo/             # ECHO 物品名稱與已辨識舊名
├─ groups/echo/            # ECHO 自訂部位名稱
└─ overrides/              # 人工修正，不被擷取腳本覆寫
   ├─ en.json
   └─ zh.json

只想補一條翻譯？

編輯 src/translations/overrides/zh.json，保留 BC 的鍵與佔位符。例如：

{
  "ChatOther-ItemHead-LSCG_Bap": "SourceCharacter輕拍了TargetCharacter的頭。"
}

一般來源檔以「英文＋所選語言」合併；人工 overrides 最後套用（英文，再所選語言）。缺少翻譯時保留英文，不必複製整份 bc-messages。UI 仍要求中英文鍵與數字佔位符一致。

src/action/generated/ 是忽略版控的建置產物，不要手改。差異檔使用共用基底的鍵索引，避免每種語言重複長動作名稱；merge.ts 在執行時還原鍵。npm run build 會自動重建，Cloudflare 不需要那些本機插件倉庫。中文覆蓋率高時差異檔仍然很大；這是維護及共用基底的改善，不保證首次中文載入更小。

新增插件或語言

插件動作新增 action/插件名稱/en.json，物品名稱新增 items/插件名稱/en.json，部位名稱新增 groups/插件名稱/en.json；每類可選 zh.json 差異，建置器遞迴發現。名稱資料不會載入服裝圖片或改寫外觀。特殊封包格式在 action/ 加入純文字解析與測試。新增完整 UI 語言還需調整 i18n 的 Locale、字典登錄與 UI 語言選單，只有新增 JSON 不會自動新增選單。

ECHO 衣物目前靜態擷取 465 個物品鍵（含部分舊名別名）及 11 個部位；動態生成、鏡像部位或執行期修改並非完整涵蓋，未知名稱保留原文。玩家 CraftName 永遠保留自訂名稱。

05 / SESSION LIFECYCLE

先驗證就緒，再開放操作。

idle → connecting → authenticating → waiting-server → ready
                                                        ↕
                                                   joining → in-room
暫時斷線 → Socket.IO 重連 → 重新登入／ServerInfo → 嘗試回原房一次

LoginResponse 與 ServerInfo 必須完成；PROD／DEV 以伺服器回覆為準。UI 訂閱唯讀快照，所有送出操作由 client 再驗證。登出、強制斷線及帳號被別處登入不會無限搶回連線。

手機回前景以既有好友查詢檢查連線。常亮／本機音訊由使用者選擇；無法保證瀏覽器在背景或鎖屏持續執行。

06 / TRUST BOUNDARIES

維持原有的資料界線。

資料／操作保存與限制
密碼、聊天、外觀快照、召喚名單分頁記憶體；不新增永久儲存或雲端 API。
記住帳號、顯示偏好、永久媒體許可自選 localStorage；並非加密保管庫。
插件動作與 AFC讀取文字／共享關係資料，不安裝插件。一般擴展互動只發送文字；ECHO 貼貼確認後只更新自己的 ItemMisc 道具並分享位置配對，不覆蓋既有道具，不支援跨房跟隨。
媒體載入先許可來源，再設定 src；來源可看到連線資訊，瀏覽器仍會跟隨重新導向。
安全詞使用者確認後的外觀改寫例外；不保證完整插件連動效果。
BCX 召喚／個人資料互動召喚採允許名單＋接受確認。原生活動預設相容發送，略過未實作的本機條件；已知禁止偏好與房間限制仍阻擋。可取消相容模式恢復保守判定，不代表完整 BC 引擎。

第三方文字沿用各來源授權：詳見 docs/third-party-dialogues.md 與 docs/licenses/，不可一律視為 MIT。

07 / DEVELOPMENT

修改來源，讓建置處理產物。

npm run catalog:compile     # 僅重新合併翻譯
npm run build               # 自動合併＋型別檢查＋Vite
npm test                    # 模擬 socket、DOM、翻譯與中繼測試
npm run dev                 # UI 與 architecture.html 預覽

更新上游資料才需要 npm run catalog:bc -- 上游BC目錄／npm run catalog:plugins／npm run catalog:items（ECHO 衣物）。擷取只覆寫對應來源資料，不覆寫 overrides。build／dev 啟動前會自動執行 catalog:compile；dev 運行期間修改翻譯後需再執行一次。

自動測試不能取代手機、真實 BC 房间及插件觀看端驗收。部署後請依 docs/community-features-tests.md、docs/mobile-connection-tests.md 檢查。
