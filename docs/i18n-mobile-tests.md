# 中英文與手機驗收

## 部署

提交變更並等待 Cloudflare Pages 正式部署成功，重新整理本站。既有建置設定不變：`npm run build`，輸出 `dist`。中文預設；登入頁／設定頁可切換 English。沒有新增後端服務或環境變數。

## 手動測試

1. 切換兩種語言，檢查登入、搜尋、建立房間、好友、設定、玩家資料、提示文字。重新整理後保留語言；帳號仍僅在勾選保存時存入本機，密碼不由 Lite 保存。
2. 請另一位玩家使用／移除一般 BC 物品、進行互動。確認顯示完整敘述、玩家名稱、物品和部位，而非 ActionUse／ActionRemove。切換語言後現有互動紀錄也應更新。自訂製作品名保持原文。未知插件動作尚可能保留鍵名。
3. 真正聊天輸入 ActionUse、Talk、null，應原樣顯示；角色 Type=Status 的同名控制封包不得出現或增加未讀。
4. 手機直向使用長房名，名稱應單列省略，不再被按鈕擠成逐字換行；點成員可查看完整房名，再按關閉成員返回。工具按鈕和送出按鈕應易點。
5. Android Chrome／iOS Safari 分別開關軟鍵盤、橫直向切換，確認輸入框與送出可見、聊天紀錄可捲動且底部導覽不擋住輸入。實際鍵盤高度仍需實機驗收，DOM 測試不等於瀏覽器排版測試。
6. 輸入中文草稿，切換設定語言再回聊天，草稿應保留；接收新訊息、好友更新時也不應打斷中文選字。測試在線／離線好友分類不依賴介面語言。

## 維護

- `src/locales/zh.json`、`en.json` 是介面翻譯來源；新增字串須同步兩份及參數占位符。產品名、命令與 BC 協定代碼保留原樣。
- `src/i18n.ts` 提供 `t(key, values)`，不解析 HTML。`scripts/extract-ui-i18n.mjs` 是已完成的一次性遷移工具，不應重跑覆寫現有翻譯。
- 遊戲訊息表由 `scripts/build-text-catalog.mjs` 產生，已隨專案保存。只有所選語言延遲載入，不載入 BC 圖像／人物渲染，也不呼叫外部翻譯服務。
- 執行 `npm run build` 再 `npm test`；測試包含語言鍵值／參數一致性、動作 Dictionary、草稿與玩家原文保留、Status 雜訊過濾。
