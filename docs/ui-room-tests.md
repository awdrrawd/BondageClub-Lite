# 房間與好友 UI 調整驗收

Cloudflare 設定不變，提交並部署本次程式後重新整理。自動測試使用模擬 socket／DOM，不會登入你的帳號，也不能代替 BC 伺服器與真手機驗收。

1. 登入頁只顯示簡短介紹；帳號保存及資料安全的完整說明可點開。頂欄登入後顯示玩家名稱、會員編號、登出。
2. 房間頁預設「搜尋房間」，「建立房間」切換到另一份表單；不應同時出現兩份表單或紅色診斷區塊。操作狀態仍在頂欄；錯誤不得靜默忽略。
3. 進房後切「房間」搜尋，再回「聊天」，房間與草稿應保留。直接搜尋不會主動離房；只有確認加入另一間時才送出離房。加入失敗不自動返回原房。
4. 用長短描述混合的房間列表核對加入按鈕底部對齊。房間顯示伺服器回傳的好友數、受限／隱藏／滿房、遊戲與地圖狀態；沒有資料時不推測好友數。好友標籤 title 提供編號。
5. 新建測試房：設定背景名稱（例如 MainHall）、描述、5 人、管理者／白名單／黑名單、可見性與加入權限。用第二個帳號在完整版 BC 核對設定。建立時保留自己為管理者；名單以編號填寫。
6. 圖片／音樂只保存為 BC 房間的 Custom.ImageURL／MusicURL；Lite 不預覽或自動載入。請使用可信 HTTPS URL。內建背景目前輸入背景代號，尚無縮圖挑選器。
7. 地圖可選 Never／Hybrid／Always 與 Fog；未匯入時依本機 BC 定義產生 40×40 空白地圖，或貼入 MapData JSON 的 Tiles／Objects／Effects。這是設定／資料匯入，不是圖形地圖編輯器。Lite 不提供地圖移動或遊戲操作，Always 可能影響距離相關互動及聊天，正式使用前先以測試房核對。
8. 點玩家查看主人／戀人，BIO 預設收合且展開才建立文字節點。缺少關係資料顯示「未提供」，不當成確定單身或無主人。私訊可切到 BEEP，房內密語仍保留。
9. 好友列先「前往房間」、再「BEEP」、最後「移除」。沒有房名就不提供前往按鈕。在線判定參考 FCM：同房成員，或 BC OnlineFriends 回覆。成功查詢未列出的好友放入「不在線」，但仍可能受隱私／互加限制；未查詢或失敗時為「未確認」。這些狀態不會背景持續輪詢。
10. 聊天送出按鈕應為「送出」，BEEP 為「送出 BEEP」。請在真手機上測中文輸入、切頁草稿、成員抽屜與長列表排版。
