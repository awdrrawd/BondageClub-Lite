02 / 模組責任

按責任找原始碼。

src/main.ts · src/ui/

入口與 UI

app.ts 訂閱快照與導覽；room-list.ts 排序房間，private-messages.ts 快取私訊視圖；activity-dialog.ts 活動選單，history-settings.ts 保存設定與匯出，history-search.ts 提供每頁 50 筆本機搜尋與同房間／對話上下文。dom.ts／contact-card.ts／icons.ts／icon-select.ts／style.css 提供元件與版面。國旗只打包實際使用的本站雜湊 SVG，以 image 共用 URL；其他圖示保留內嵌 SVG。

src/network/ · src/shared/

協定與快照

正式 main.ts 注入 client 建立 UI，預覽入口注入模擬 client；匯入 UI 不自動啟動。client.ts 唯一擁有 Socket.IO，管理登入、搜尋、房間、好友與送出驗證。speech.ts 只附加發送者分享的 Original。shared/types.ts 定義協定資料子集；ui/client-contract.ts 與 extensions/types.ts 保存型別契約，不載入網路實作。extensions/api.ts 提供 BCLite v1：分類的新訊息事件、有限狀態與受檢查的發送入口；不暴露帳密、Socket 或外觀寫入。

src/storage/

本機紀錄

history.ts 提供白名單、IndexedDB v2、索引查詢與清理；history-export.ts 產生獨立 HTML 與純文字儲存格的 XLSX；history-session.ts 增量收集、批次重試、快取視窗及競態隔離，不操作 Socket。

src/action/

文字與活動

catalog／merge 載入文字表；embedded／render 處理替代文字與字典；native／extensions／labels 判定與標籤；cuddle 管理確認配對。

src/translations/ · src/i18n/

翻譯

可編輯 JSON 與 UI 翻譯函數分離，支援中、英、俄文。俄文動作／道具取自原版 RU；缺漏回退英文，角色與物品替換標記不一致時不採用譯文。玩家聊天、BIO、房名與 CraftName 不自動翻譯，不呼叫遠端翻譯。

src/profile/ · media/ · safety/ · platform/

邊界功能

BIO／好友名稱／AFC；媒體來源許可與生命週期；安全詞與裝飾資料保護；手機手勢、常亮／本機音訊及確認對話框。

src/preview/ · scripts/ · tests/ · public/

開發與部署

虛構 UiClient 重用正式介面；腳本編譯／擷取資料；測試模擬協定、DOM、儲存；public 包含 Worker、標頭、路由與公開授權。

03 / 登入與恢復

先認證，再操作。

idle → connecting → authenticating → waiting-server → ready
                                                        │
                                                     joining → in-room
                                                               │
                                                            ready（離房）
暫時斷線 → reconnecting → 認證／ServerInfo → 嘗試回房一次

回房順序：斷線前記憶體房名 → 本機帳戶／環境房名 → BC LastChatRoom。主動離房等操作寫入 null，阻止舊房名回退；失敗不循環加入、不創建房間。手動登出／強制下線不搶回帳號。

搜尋序列化，只保留最後待查條件；逾時且有新查詢意圖時重新連線認證，隔離沒有請求 ID 的舊回覆。前景 OnlineFriends 探測可由任何正常已認證事件完成，12 秒無回應才重啟傳輸。不補傳聊天。

常亮與本機音訊預設關閉，不保證手機背景執行。同帳戶自動重連保留既有安全詞基準；手動登出再登入、刷新或身分改變才建立新基準。

暫時斷線保留聊天 DOM 與草稿，真實連線狀態控制送出，不自動重送。私訊依玩家累計本次工作階段未讀，可定位第一則未讀與手動標記已讀。message-sounds.ts 提供預設關閉的 BEEP／悄悄話獨立短音開關，偏好存在 localStorage，不使用桌面通知。

04 / DOM 更新

資料同步不等於重建畫面。

BC 事件 → client.patch → 新快照
                           ├→ HistorySession.observe → 待寫批次
                           └→ LiteApp → 結構判斷／局部 DOM 更新
觸發更新方式
同帳戶／連線階段／房名不變保留 shell，只更新標頭、成員、房間、好友、搜尋結果及訊息。
角色外觀／道具或重複同房同步成員按會員編號更新，未變節點不替換；點擊時讀最新快照。
新訊息／修正按 ID 維持順序，僅替換更正列；沒有陣列改變時跳過聊天處理。
抽屜／公開翻頁／公開回覆與取消／引用跳轉局部操作，保留輸入框與重疊訊息列。
首次掛載、帳戶／連線階段／房間切換、主動切頁／對話／語言／部分設定仍可能結構重建；中文組字期間延後。
每分鐘歷史觀察不是 UI 重建計時器；約每小時檢查到期清理。

房間 live ring 可選 600／1500／3000 則，DOM 每批 50／100／200（預設 100）；私訊 DOM 每頁 60 則。閱讀舊頁不強制跳底，移除節點前釋放媒體，未變的播放器保留掛載。

05 / 本機歷史

顯示上限、快取與磁碟期限分開。

  1. 不可變訊息版本新物件代表新增／修正；弱參照集合跳過已處理版本，只對變動內容建立白名單並序列化。陣列身分檢查仍有成本。
  2. 350ms 批次寫入按 ID 去重，失敗批次保留並最多自動重試三次；世代與請求序號隔離舊帳戶／舊載入結果，清除與寫入序列化。
  3. IndexedDB v2bc-lite-history 的 messages／contacts 按環境與玩家 ID 分區；訊息預設 7 天、聯絡人 30 天，可縮短或關閉。只保存顯示欄位，不含 Dictionary、BIO、外觀或帳密。
  4. 有上限的私訊視窗啟動各讀最多 3000 筆房間／私訊；私訊快取共最多 3000 筆，開啟對象 600 筆、其他對象共 2400 筆。雙向每批 60 筆，以時間＋唯一鍵處理同時刻訊息。
  5. 磁碟查詢與匯出搜尋支援關鍵字、玩家、房間、日期與頻道，透過索引游標每頁 50 筆；上下文前後各 10 筆，同房間／對話隔離。淘汰不刪磁碟，舊視窗不插入最新訊息；向後翻頁可回最新。按日 TXT／HTML／Excel (.xlsx) 匯出讀完整未過期磁碟紀錄，預設排除私人訊息。

06 / 文字與活動

文字相容與活動效果分開。

  1. 過濾控制訊息Hidden／Status 不顯示為普通聊天；Chat／Whisper 可附加發送者提供的 Original，並非破解。
  2. 選句與字典代入embedded 處理可讀插件原文；render 代入玩家、物品與部位，UI 用 textContent／安全連結呈現。插件原文可能不隨介面重譯。
  3. 送出前再判定原生活動送 Activity，一般擴展項目送文字 Action；已知工具、目標偏好與房間規則仍檢查。Lite actor policy／相容模式不是完整 BC 引擎。
安全詞與 ECHO 貼貼是明確確認的外觀寫入例外。貼貼只改自己的 ItemMisc 並提交房間外觀，不替對方操作。沒有角色繪圖、衣櫃、完整興奮／表情或插件效果引擎。

AFC 只查自己的共享關係；BCX 相容召喚使用允許名單與手動接受，不強制跟隨。BCLiteHello 只有 client: Lite；徽章需要觀看端支援，自報不等於身分驗證。

07 / 翻譯建置

編輯來源，編譯基底與差異。

src/translations/
├─ ui/                 # en.json / zh.json，UI 字典
├─ bc/                 # messages / actions / items / groups
├─ action/             # xiaosu / lscg / echo
├─ items/echo/         # ECHO 名稱
├─ groups/echo/        # ECHO 部位
└─ overrides/          # 人工覆寫，最後套用

compile-action-catalogs → src/action/generated/
catalog.ts → 英文基底 + 所選語言差異 → merge.ts

generated/ 是忽略版控的產物，不手改。build／dev 前置步驟重新編譯；dev 運行中修改翻譯需另跑 catalog:compile。新增插件資料由編譯器發現；完整 UI 新語言仍需更新 Locale、字典登錄與選單。

首次中文登入需英文基底與中文差異，不是只下載單一中文包。體積與條目數以當次建置為準；沒有翻譯時保留英文／原文。上游擷取才需要本機 BC／插件來源，正式部署不執行插件腳本。

08 / 資料與權限

說清楚保存位置與例外。

資料界線
密碼／外觀基準／草稿／召喚名單分頁記憶體；不存歷史資料庫。
帳號、偏好、許可、最近房名localStorage 明文；記住帳號為自選，其他項目各依自身操作保存。
訊息／最近聯絡人IndexedDB 明文，預設啟用期限保存；登出不等於刪除磁碟紀錄，不新增雲端歷史 API。
外觀更新一般操作保留未知 bundle；安全詞與確認貼貼可寫入，OnlineSharedSettings 不改動。AEE／SCA 裝飾保護不等於插件渲染。
媒體以實際播放器 origin 許可，影音另點擊開啟，同時一個播放器。支援指定服務 iframe；来源可接收 IP、Cookie 或載入次級資源。

帳戶分區不是加密；匯出檔不受網站期限管理。第三方文字、圖片與圖示沿用各來源授權，不能一律視為 Lite 的 MIT。授權全文留於倉庫 docs/licenses/ 與相應 public/licenses/。

09 / 開發驗證

先本機檢查，再真人驗收。

npm ci
npm run build              # 文字編譯、型別檢查、Vite
npm test                   # 協定、DOM、儲存、文件／建置
npm run dev:ui             # 免登入虛構資料
npm run dev:relay           # 先 build；本機 Pages Worker
node scripts/smoke-relay.mjs # 不登入的握手測試

UI 預覽透過 UiClient 注入資料，不開歷史 IndexedDB、外部媒體受預覽 CSP 阻擋，ui-preview.html 不進正式建置。Vite dev 本身不提供 Worker。

happy-dom、fake-indexeddb 與模擬 socket 驗證節點身分、排序及競態，不能取代實機排版、軟鍵盤、背景恢復、Cloudflare PROD 或雙人插件驗收。測試數與 bundle 體積不固定抄寫，使用當次輸出。
