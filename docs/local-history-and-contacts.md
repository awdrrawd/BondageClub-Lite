# 好友、私聊與本機紀錄

## 名稱與狀態

`src/profile/friend-names.ts` 按 BC 的 Login.js 解壓 UTF16 FriendNames 配對陣列；不修改伺服器名稱資料。名稱優先序為同房間 Nickname／Name → FriendNames → 最近好友查詢 MemberName → 最近聊天名稱／AFC 名稱 → ID。好友查詢可在記憶體補齊缺少的名稱，不寫回 AccountUpdate。

好友頁預設在線，分頁選擇只存記憶體。私聊的好友頁只列已確認在線的玩家；最近聊天保留離線／狀態不明者，以灰色顯示，選取後恢復正常。整張卡片預設開啟私訊；悄悄話只有同房間能選。BC 的好友隱私會影響查詢結果，Lite 不會繞過隱私來確認在線狀態。

## 保存責任

- `src/storage/history.ts`：資料白名單、帳戶鍵、到期判斷、IndexedDB 交易、按裝置本地日期分组 TXT 匯出。
- `src/storage/history-session.ts`：快照增量收集、350ms 合併寫入、還原私聊、帳戶切換競態隔離。不接觸 Socket。
- `src/ui/app.ts`：快照訂閱、分頁及統一帳戶切換清理；不把還原訊息送回遊戲。
- `src/ui/history-settings.ts`：保存設定、日期索引與單日匯出；所有非同步結果再次核對帳戶／環境。
- `src/ui/contact-card.ts`、`private-messages.ts`、`dom.ts`：聯絡人卡片、私聊排序快取、共用 DOM 元件。

資料庫 `bc-lite-history` 含 `messages`、`contacts` stores，鍵包含伺服器環境與玩家 ID。只保存訊息的顯示文字、時間、發送／接收者、訊息類型、房名和回覆識別；不保存密碼、Appearance、BIO 或原始協定 Dictionary。登入時讀取該帳戶的備份，房間訊息僅還原最新的設定上限筆數；保留原始房名，不因換房而重標記舊紀錄。私聊恢復後仍分批顯示。顯示上限與 IndexedDB 保存期限分開。

即時房間訊息不因重連、離房、換房而清空，只在手動清除或超過筆數上限時移除。磁碟副本仍按保存期限清理，已載入的即時列表不受磁碟到期影響。刷新／重新登入只能恢復尚未過期且成功寫入的備份。切換帳戶或 PROD／DEV 時重置即時資料，還原操作再次核對環境和玩家 ID。聊天室清除按鈕會同時刪除該帳戶環境的房間備份，不影響私聊或其他帳戶，並阻止未完成的歷史載入把紀錄加回。

| 項目 | 預設 | 可選期限 |
| --- | --- | --- |
| 最近聯絡人（ID、名稱、最後訊息時間） | 30 天 | 關閉、7、14、30 天 |
| 房間訊息 | 7 天 | 關閉、1、3、7 天 |
| 私訊與悄悄話內容 | 7 天 | 關閉、1、3、7 天 |

時間取自原始訊息，重繪或重新開啟不會刷新資料年齡。每筆有到期時間；縮短期限／關閉保存會逐筆刪除過期資料。啟動、登入、設定改動、匯出前及使用期間約每小時清理；關閉網頁時無法執行清理，背景分頁亦可能延後。瀏覽器強制終止可能使最後尚未完成的批次丟失。網站資料清理或瀏覽器空間回收也可能刪除紀錄。

「清除此帳戶已存紀錄」只清除目前環境／帳戶，保留目前畫面的 live ring，也不會因重繪或補上翻譯把該 live ring 存回；其後新收到的訊息仍按設定保存。儲存失敗會提示，不影響即時聊天；失敗批次留在記憶體，自動重試最多三次（1／2／4 秒），之後新訊息、匯出或再次寫入可重試。關閉瀏覽器仍可能失去尚未成功保存的批次。

IndexedDB v2 保留 v1 資料並補上帳戶／類型／時間、帳戶／對象／時間、帳戶／日期及到期索引。登入最多讀取各 3000 筆房間／私聊訊息，並由客戶端套用房間顯示上限；私聊較舊內容按對象每批 60 筆讀取。同時間訊息以唯一鍵作分頁邊界。設定頁只讀日期鍵和筆數，下載時才讀取指定日期的內容。例行清理只查到期索引；登入套用保存政策或修改政策時才走訪該帳戶資料，不重寫到期時間未變的資料。

帳戶識別統一使用「環境＋玩家 ID」。即使未經登出畫面就切換身分，也會清除草稿、回覆對象、暫時媒體許可、召喚授權、選取聯絡人與分頁；同一身分重連則保留草稿。私聊排序結果由訊息陣列版本共用，訊息列表和分頁不重複排序。

歷史收集以不可變訊息物件辨識新增／修正，只為未處理的版本建立白名單資料並序列化。一般新增訊息仍會檢查陣列中的物件身分，但不再複製或序列化整個 live ring；帳戶、房間或自身名稱變更時重新檢查相關內容。修改訊息時必須建立新物件，不能原地改寫既有物件。

私訊歷史快取最多 3000 筆。開啟對話時載入該對象最新最多 600 筆，其他對話共保留最近最多 2400 筆；往前或往後讀取時每批 60 筆移動視窗。快取淘汰不刪磁碟紀錄，翻回被淘汰的部分會重新查詢 IndexedDB。閱讀較舊視窗時，新訊息照常保存，但不插入正在閱讀的頁面；逐頁向後可回到最新。載入期间暫停翻頁按鈕，切換對象後忽略舊請求結果。每日匯出仍讀取完整的未過期磁碟紀錄。

## 匯出與隱私

參考 `Liko - CHE.main.user.js` 的按日／按帳戶概念，不載入 CHE、不讀它的資料庫，也不使用它的加密金鑰。設定 → 保存 → 選擇日期及格式 → 匯出當日紀錄。HTML 預設選取，另可選 Excel (.xlsx) 或 TXT；HTML／TXT 同一天按房名分組。預設不含私訊與悄悄話，需額外勾選；三種格式均保留玩家文字，不執行玩家 HTML、不載入遠端圖片。動作保存顯示譯文；若仍在即時列表的同一則訊息補上翻譯或文字修正，備份會更新，但保留原始時間及到期時間。不為離線舊紀錄重新載入原始協定或翻譯服務。

這是**本機明文紀錄，不是加密保管庫**。帳戶分區只避免 UI 混用資料，不防止同來源程式、擴充功能或可操作此瀏覽器的人讀取。匯出檔離開網站保存期限管理，需自行保護與刪除。新增的歷史副本不另傳雲端；既有遊戲流量仍會經 Cloudflare 中繼，不能據此宣稱遊戲帳密或聊天從未經伺服器。

## 外觀與圖示

設定提供外觀／功能／效能／保存／隱私分類跳轉，主題為經典紫、午夜藍、森林綠，僅本機偏好。flag-icons 的 HK／GB SVG 分別搭配中文／English 文字標籤；房間語言另含 DE／FR／ES／RU／UA。桌面與手機共用 SVG 選單，保留語言名稱。SVG 隨站打包，不請求 CDN；MIT 授權位於 `public/licenses/flag-icons-MIT.txt`。刷新圖示來自 Phosphor，沿用其 MIT 授權。

## 測試

1. `npm run dev:ui` → `/ui-preview.html`：不登入、不開 IndexedDB，只使用虛構且刷新即消失的訊息；可測主題、篩選、卡片及 TXT／HTML／Excel 匯出。
2. 正式登入後檢查一個同房好友、一個異房好友、一個離線好友：核對名字、房間副標題及預設私訊頻道。
3. 互傳私訊／悄悄話，等待至少一秒後刷新並以同帳戶登入：最近聊天與內容應恢復。换帳戶或 DEV／PROD 不應顯示前一帳戶紀錄。
4. 設定 → 保存：匯出當日紀錄，核對預設排除私人訊息，勾選後才包含；關閉保存需确认刪除。
5. IndexedDB 的刷新、到期、分區、錯誤與帳戶切換竞态由 `tests/history.test.mjs` 使用 fake-indexeddb 測試，不需等待真實 30 天。手機背景清理時機與下載行為仍需真機驗證。

## 搜尋與未讀

房間工具列及設定內可開啟本機搜尋，支援文字、玩家編號／名稱、房名、起訖日期與頻道；每次顯示 50 筆，下一頁替換結果。點擊結果可讀同房間或同對話前後各 10 筆，不切房、不送訊息、不載入媒體。只能搜尋目前帳戶且尚未到期的已保存內容。

私訊卡片及導覽顯示依玩家累計的未讀。切換對話仍保留未讀，可定位第一則或手動標記已讀；不代表伺服器回條，也不跨重新載入保存。首則未讀超出快取時開啟本機上下文；已刪除／到期則提示不可用。

### HTML 與 Excel 格式

參考 CHE 的閱讀頁及 Time／ID／Name／Content 表格概念，實作使用 Lite 已保存的白名單資料，不複製 CHE 模板或引入遠端 XLSX 程式庫。HTML 是無腳本、無外部資源的獨立頁面，按房間分段並支援瀏覽器搜尋及列印。Excel 為真正的 .xlsx，ChatLog 工作表含本機時間、房間／對話、頻道、發送者編號／名稱、接收者編號／名稱與訊息；標題列凍結、欄位可篩選、訊息換行顯示。所有欄位以文字保存，包含以等號開頭的訊息，不產生公式或超連結。

Excel 每格最多 32767 字元；超出時提示改用 HTML／TXT，不截斷原文。匯出仍受當日、帳戶與私人訊息勾選限制，點擊時重新查詢保存資料，產生中停用重複下載。檔案不會因網站刪除紀錄而自動刪除。
