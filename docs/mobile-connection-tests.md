# 手機連線恢復與背景輔助

## 行為與資料

- 回前景、pageshow、online 會觸發檢查，只在頁面可見且未回報離線時執行；15 秒內重複事件合併。已連線時用原生 OnlineFriends 唯讀查詢，12 秒未收到回應才重啟傳輸。進背景或離線會取消檢查計時器。
- 保留 Socket.IO 自動重連。暫時斷線記住原房於記憶體，重新登入與 ServerInfo 完成後回房一次。失敗不循環重試、不建立房間、不補傳漏掉的聊天。手動離房清除目標；登出、強制斷線及重複登入不搶回帳號。
- 設定 → 連線與背景輔助：可選常亮、本機音訊循環播放、暫停、手動檢查與診斷。常亮只在前景有效，系統可能拒絕；回前景重取。背景音訊不保證 BC 在線。預設關閉，本次分頁有效，登出或錯誤終止後停止。
- 本機音訊使用 Blob URL，不上傳、不自動播放，登出釋放。最多 80 筆診斷只含時間與固定事件代碼，不記帳密、房名、聊天或任意錯誤字串。不寫 localStorage、不上傳；登出清除。
- 系統回收頁面或重新整理後仍需重新登入，不持久化密碼。重連重新登入會建立新的安全詞登入快照。

## 實機測試

1. 請另一位好友觀察在線及房間狀態，不要只看音訊是否播放。
2. Wi-Fi／行動網路切換、短暫飛航再恢復：應登入後回房一次。房滿／房間消失時停止嘗試。
3. 切其他 App、切分頁、鎖屏各 1／5／15 分鐘，分別比較不播音訊與播放本機音訊。記錄手機、系統、瀏覽器版本、省電模式及網路。
4. 回前景应檢查連線，不重複回房、不打斷草稿；若系統回收整頁，記憶體草稿與聊天不能保證保留。
5. 診斷常見事件為 hidden、visible、offline、online、ping timeout、transport close、resume-check、probe-response、resume-probe-timeout、connected、rejoin-attempt。
6. 另一裝置登入時 Lite 不應搶回；登出後切網路或回前景也不應登入。音訊與常亮應停止。
7. 常亮不支援／被拒絕時應提示，不影響聊天。選擇音訊後按播放才開始，切 Lite 分頁不中斷，暫停可停止；手機系統仍可能停止背景播放。

自動測試使用模擬 socket／DOM，不能替代實機背景測試。部署設定不變；安全標頭新增 media-src blob: 以載入本機音訊。
