# 手機介面、連線恢復與登入回房

[文件導覽](README.md) · [部署與驗收](deployment-and-tests.md) · [架構導覽（HTML）](https://bondageclub-lite.pages.dev/docs/architecture/)

## 手機介面

760px 以下採手機布局：頂欄圖示／玩家／安全詞，右側語系／登出；底部分頁依序搜尋、房間、私聊、好友、設定。長名稱省略，成員面板可查看完整房名。桌面與手機共用本機 SVG 選單，語言具文字標籤。

搜尋欄包含關鍵字、搜尋、分區、語言與篩選；手機聚焦關鍵字時擴展，保留搜尋按鈕，失焦／點別處縮回。分區協定值空字串＝女性、M＝男性、X＝混合。結果列為總數／分頁／排序，手機每頁 8 間、桌面 24 間。手機橫向滑動翻頁不攔截垂直捲動。

使用動態視窗高度與底部安全區；不把 DOM 測試等同實際軟鍵盤適配。常亮與音訊不是保持 BC 在線的保證。

## 搜尋與前景探測

登入後自動搜尋所選區域；切區清空關鍵字再查，切語言亦查。滿房、語言等條件仍有效，隱藏房需完整名稱。快速連切只保留最後待查條件。

搜尋序列化；BC 回覆無請求 ID。搜尋逾時且有待查詢／重試意圖時，重新連線認證後查詢以隔離舊回覆，可能暫時離房；沒有新意圖不因一次逾時循環重連。

visible／pageshow／online 在可見且未回報離線時啟動探測；15 秒內合併重複事件。已連線時發 OnlineFriends，任何正常的已認證伺服器事件都可結束探測，12 秒無回應才重啟傳輸。進背景／離線取消檢查計時器。不自動補傳聊天，斷線提示可能漏訊息。

## 登入回房

LoginResponse 與 ServerInfo 通過後嘗試回房一次，優先序：

1. 暫時斷線前的記憶體房名。
2. 當前帳戶／環境的本機房名。
3. BC 回傳的 LastChatRoom.Name。

成功 ChatRoomSync 才寫入 `bc-lite-last-room-v1:<編碼環境>:<玩家ID>`，值只有 JSON 房名。主動離房、被踢或加入遭拒寫 null，阻止回退至舊房名；正常登出保留房名。房間不存在、滿員或權限拒絕就顯示結果，不循環重試、不創建房間。

房名是瀏覽器明文資料；清除網站資料可移除。儲存不可用時仍可登入，但僅能依記憶體／BC 資料回房。不是免密碼登入。強制下線、重複登入及手動登出不搶回帳號。相同帳戶自動重連保留已有安全詞基準；手動登出再登入、刷新或身分改變才建立新基準。

## 背景輔助與診斷

設定可選常亮、本機音訊播放／暫停、手動檢查及診斷。預設關閉；常亮僅前景有效，系統可能拒絕，回前景重取。音訊以 Blob URL 使用本機檔案，不上傳、不自動播放；切 Lite 分頁維持掛載，登出／錯誤時停止及釋放。

診斷最多 80 筆固定事件代碼與時間；不含帳密、房名、聊天或任意錯誤內容，不持久保存、不上傳，登出清除。系統回收頁面後記憶體草稿可能消失，歷史僅能恢復尚未過期且成功寫入的部分。

## 實機驗收

1. 320／390／760px 與長名稱：頂欄控制可操作，搜尋聚焦、Tab、Escape、點別處及五個導航 SVG 正常。
2. Android Chrome／iOS Safari 軟鍵盤開關、橫直向切換：輸入框及送出按鈕可見，聊天可捲動、不被底部導航遮住。
3. 中文組字時收到訊息、成員／外觀／房間同步及好友回覆，輸入框身分、草稿、游標應保留；切語言後草稿仍在。
4. 登入後自動搜尋，快速切區與語言，只呈現最後查詢。探測期間好友回覆慢但聊天持續時，不應誤判斷線。
5. Wi-Fi／行動網路切換、短暫飛航後登入回房一次；房滿／消失／被封鎖時停止，不補送旧聊天。
6. 房內登出再登入、刷新重新登入應嘗試回房；先手動離房再登入停在搜尋。換帳戶／環境不使用前一身分房名。
7. 切 App／分頁／鎖屏各 1、5、15 分鐘，對照有無播放本機音訊；記錄裝置、OS、瀏覽器、省電模式、網路及部署版本。由另一帳號確認在線，不能只看音訊。
8. 另一處登入同帳號時不搶回；登出後切網路／回前景不登入。常亮拒絕時提示且不影響聊天，音訊手動播放／暫停正常。

模擬 socket／DOM 不取代實機背景、真正重連與 Cloudflare 部署驗收。

## 斷線閱讀驗收

暫時斷線時保留房間閱讀畫面及草稿，顯示連線提示並停用發送。驗收 reconnecting → waiting-server → ready → 同房 in-room 期間輸入框節點及內容不變，恢復後不自動送出；只有真實房間恢復才啟用房間發送。換帳戶或登出清除畫面暫存。
