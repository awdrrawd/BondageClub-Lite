# 登入回房

登入通過 LoginResponse 與 ServerInfo 後，自動嘗試加入一次：優先使用斷線前的記憶體房名，其次使用當前玩家／環境的本機房名，最後才使用 BC 回傳的 LastChatRoom.Name。房間不存在、滿員或權限拒絕時顯示原加入結果，回搜尋介面，不循環重試、不重建房間。

成功收到 ChatRoomSync 才寫入 `bc-lite-last-room-v1:<Environment>:<MemberNumber>`，值只有 JSON 房名。主動離房、被踢或加入遭拒會寫入 null，避免使用伺服器舊資料重新拉回；正常登出保留房名。帳密、外觀、聊天紀錄不寫入此項目。這是瀏覽器明文儲存，同源程式或同裝置使用者可能讀到，清除網站資料可刪除。禁用儲存時仍可登入，但回房只能依當前記憶體／BC 資料。

部署後測試：

1. 成功進房後重新整理，重新登入同帳號，應直接嘗試回房。
2. 房內登出再登入應回房；先按「離開」再登出登入則停在搜尋。
3. 改用另一帳號或 DEV 環境，不應套用前一帳號／PROD 房名。
4. 房間解散或被禁止加入，應顯示失敗，不能自動創建或連續嘗試。
5. 網路中斷重連維持原有回房；強制下線／重複登入不自動搶回連線。

首次使用新版若沒有本機記錄且 BC 沒提供 LastChatRoom，仍需手動進房一次。此功能不新增免密碼登入。
