# 房間、好友、聊天與 DOM 驗收

[文件導覽](README.md) · [本機歷史](local-history-and-contacts.md) · [活動與社群協定](chat-native-identity-tests.md) · [架構導覽（HTML）](https://github.com/awdrrawd/BondageClub-Lite/blob/Mater/docs/architecture.html)

## 介面與訊息

- 互動入口只保留 SVG 部位格子與標籤，移除人物輪廓和下方部位列表；桌機顯示部位＋3／4欄動作。760px 以下分成部位頁、動作頁，可返回部位。缺少原生 Zone 的擴展部位放在旁邊的輔助格。
- 私聊採桌機左側分類／人員、右側對話；手機合併為清單／對話切換，返回按鈕不清除草稿。
- 原生 ServerEnter／Leave／Disconnect／Ban／Kick 通知置中，不另附作者前綴或回覆按鈕；成員同步只更新名單，不再自產第二則進出通知。離房角色暫存在最多 100 人的記憶體快取，換房／登出清除，供延後抵達的通知讀取名字。
- BC LabelColor 直接來自角色共享封包。只接受六位 hex 色；暗色混入白色直到對 #30213a 對比達 4.5:1，缺值則依 ID 使用固定配色。不寫回遊戲。
- 清除只清本機公開聊天室紀錄；不發送刪除封包、不清私聊，不清正在輸入的草稿。
- 回覆預覽移入 InputChat 所在表單上方；有原生 ReplyId 的引用可點回原訊息。已超出本機保存範圍、已清除或不屬於該私聊通道的引用不顯示內容。沒有原生訊息 ID 的回覆仍以純文字引用送出，不能讓接收端憑文字反查原訊息。

## 效能判斷

聊天室預設最多保存 3000 則，預設渲染最後 100 則。設定頁「減壓設定」可選保存 600／1500／3000 則，每批顯示 50／100／200 則。「更多紀錄」切到較早一批，不逐次累積 DOM；回覆跳轉只載入包含原文的那一批，可用新訊息按鈕回最新處。私聊仍預設 60 則，悄悄話跳轉最多 300；不是完整捲動虛擬列表。

`bc-lite-performance-v1` 只保存數量偏好。房間 live ring 不因換房而清空；訊息另按期限寫入 IndexedDB，登出／刷新後可恢復成功保存的紀錄。降低即時上限需確認，提高上限不立即補回被截斷的訊息；磁碟紀錄與顯示上限分開，見[本機歷史](local-history-and-contacts.md)。

公開訊息與私聊使用 ID 比對增量更新，保留舊節點與已載入媒體。一般公開訊息不連帶重建聯絡人清單。翻閱公開舊紀錄時暫停更新可見切片，避免捲軸跳動。

同一帳戶、連線階段與房名不變時，伺服器同步只更新對應區域：成員按會員編號更新、房間資訊原地修改、搜尋結果與好友卡片保留未變的節點。角色外觀／道具同步、好友查詢回覆、伺服器人數及每分鐘歷史維護不重建整個畫面。訊息修正僅替換有改動的列，聊天翻頁保留重疊列並維持順序；成員抽屜、公開訊息回覆及取消回覆也不替換輸入框。

整頁重建仍用於首次掛載、帳戶／連線階段／房間切換，以及使用者主動切換頁面、對話、語言或部分顯示設定。這是目前的更新邊界，並非所有互動都已改成局部更新。中文組字期間延後結構切換，普通同房同步可直接局部更新。

目前不導入 VDOM：它解決更新差異計算，並非自動減少長列表、媒體解碼或版面繪製。React 同樣先計算差異，再提交必要 DOM 修改，參考 [React Render and Commit](https://react.dev/learn/render-and-commit)。若實機測量顯示每批訊息、尤其圖片／影片時仍慢，下一步應優先考慮可變高度虛擬列表和媒體生命週期；不能僅用 DOM 模擬測試承諾不卡頓。

## 搜尋、建房與好友

- 搜尋／建立切成兩個表單；房內搜尋不離房，加入其他房間先確認。取消不離房，確認失效或加入失敗不自動創建房間。快速切區與逾時恢復見[手機與連線](mobile-connection-tests.md)。
- 房間卡片按名稱／好友／人數排序，滿房或不可加入置底。描述長短不影響加入按鈕對齊；好友、可見性、權限、遊戲及地圖標記取自伺服器，不猜測未提供的資料。
- 建房支援背景代號、描述、2／5／10 人、管理者／白黑名單、可見性／權限、遊戲、禁止類別與地圖。保留自己為管理者；Custom.ImageURL／MusicURL 僅作設定提交，不自動預覽。
- MapData 支援 Never／Hybrid／Always、Fog 與 Tiles／Objects／Effects JSON；未匯入時可建立預設空白資料。不是圖形編輯器，不提供地圖移動；以完整版第二帳號核對實際權限與設定。
- 好友分類為全部／在線／不在線／未確認。同房成員或成功 OnlineFriends 回覆作在線依據；隱私／互加會影響結果，未查到不代表確定不在線。清單不做固定背景輪詢，前景探測可刷新。
- 好友卡片預設開私聊，名字優先序及本機聯絡人見[本機紀錄](local-history-and-contacts.md)。同房可選悄悄話，跨房用 BEEP；目標離房後保留草稿並切回 BEEP，**不自動送出**，下次送出前須核對通道。
- 私聊草稿依對象分開；聊天與私聊各有輸入區。普通 BEEP 使用 AccountBeep，不含自己的房間位置；FCM 附件／控制封包不當成文字，不提供離線投遞或送達／已讀回條。
- 個人資料顯示原生／AFC 關係，未提供關係時 UI 顯示無；這不證明上游完整分享所有資料。BIO 預設收合，展開才解析 BC 的 ╬ + LZ-String UTF16，也支援普通文字，不修改 Description。

## 文字、語系與回覆驗收

1. 雙向測一般聊天、`/me 動作`、`*動作*`、`(OOC)`、`.a 動作`／`.A 動作`、`/w 編號 內容`，Shift+Enter 換行。離線送出不得清草稿，也不排隊自動補送。
2. 同房 Whisper 只到對象；跨房普通 BEEP 使用 BC 原生／FCM 文字互通。對象 A／B 來回切換不混用草稿，登出清除草稿；已保存歷史依期限保留。
3. 回覆有原生 MsgId 時送 ReplyId，否則文字引用；BEEP 用文字引用。公開回覆不能洩漏私聊內容，切換通道、取消及送出後清除選取；不可引用不屬於當前通道的私訊。
4. 聊天輸入 ActionUse、Talk、null 或動作鍵名，保持原文；Type=Status／Hidden 不作普通訊息或未讀。Dictionary.Original 僅顯示發送者分享的原文，相同文字不重複，沒有原文不還原。
5. 用 BC／小酥／LSCG／ECHO 活動核對玩家、物品、部位與舊／新字典格式。玩家 CraftName 保留原文；未知鍵名與缺翻譯可保留英文／原文，不偽造含義。
6. 中、英、俄文切換涵蓋登入、搜尋、建房、好友、設定、個人資料與提示；語言在頂欄選擇並保存。文字表晚到時更新仍在記憶體的動作，不能把普通聊天重譯；BIO 的 HTML／腳本僅作文字。
7. Network 核對登入後英文基底＋所選語言差異，沒有遠端翻譯／人物圖片。不要沿用舊文件的固定 bundle 大小；編譯及翻譯維護見[貢獻指南](../src/translations/README.md)。

## 外觀與語言選單

設定提供外觀／功能／效能／保存／隱私分類跳轉，主題為經典紫、午夜藍、森林綠，僅本機偏好。flag-icons 的 HK／GB／RU SVG 分別搭配中文／English／Русский 文字標籤；房間語言另含 DE／FR／ES／RU／UA。桌面與手機共用 SVG 選單，保留語言名稱。國旗以本站獨立 SVG 檔隨站打包，不請求 CDN；MIT 授權位於 `public/licenses/flag-icons-MIT.txt`。刷新圖示來自 Phosphor，沿用其 MIT 授權。

## 版面與 DOM 手動測試

1. 桌機寬度與手機 360／390px：互動只見格子；手機點部位後不應同時看到部位與動作。返回、Esc／X、Tab／Enter 均可操作。
2. 私聊切換房間／好友／最近聊天、開啟對象、返回清單。切換對象保留各自草稿；新私訊抵達不重新載入舊圖片或搶走輸入焦點。
3. 兩個測試帳號交替進房、離房、斷線，只看到一則置中通知；暱稱與名稱不同時顯示「暱稱 [名稱]」。重複的網路業務封包本身不在這次去重範圍。
4. 使用亮黃、黑色、深紫色 LabelColor，核對訊息作者與成員名稱清楚可讀。長按訊息仍可複製；懸停／點選訊息可見框線。
5. 回覆後在 InputChat 上方看到預覽；收到帶 ReplyId 的訊息，點引用可跳到舊紀錄並亮起。公開引用不能讀出悄悄話內容。
6. 閱讀舊紀錄時清除訊息，畫面應立即清空；輸入草稿與私聊保留。清除後舊引用顯示不可用。
7. 同房另一人反覆變更外觀、進出或修改房間描述；同時保持中文組字、文字圈選及已開啟媒體。輸入框和未變的訊息列應保持同一 DOM 節點，只有成員／房間欄位更新。靜置超過一分鐘也不應整頁重建。
8. 在搜尋欄或私訊框輸入草稿，再更新搜尋結果／好友在線狀態。草稿、焦點及未變動卡片應保留；私訊對象離房時停用悄悄話並切回 BEEP。

自動測試使用模擬 Socket 與 happy-dom；未取代手機觸控、實際版面和遊戲端驗收。
