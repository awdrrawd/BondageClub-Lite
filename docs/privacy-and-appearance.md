# 帳號保存、資料流向與最小外觀保護

## 自願記住帳號

- 預設關閉。勾選或勾選後提交登入時，僅把去除首尾空白的帳號名稱明文寫入 `localStorage['bc-lite-account-v1']`。
- 不儲存密碼、登入憑證、好友、外觀或聊天紀錄。顯示偏好（含中英文語言選擇）另存於 `bc-lite-display-v1`。翻譯使用本站靜態文字表，不將聊天送往外部翻譯服務。
- 此選項不會另外呼叫保存帳號 API；登入時仍需把帳密送給 BC 驗證。
- 下次開啟同一瀏覽器／同一網站來源可預填帳號；不同網址或瀏覽器不共用這份 localStorage。登出不會刪除保存的帳號。
- 取消勾選、設定頁「刪除本機保存的帳號」、或瀏覽器清除本站資料可刪除；刪除失敗會提示。刪除保存資料不等於立即清空目前表單，也不會刪除瀏覽器密碼管理器的紀錄。
- 與瀏覽器內建帳密管理器互相獨立。Lite 不要求密碼管理器保存密碼；瀏覽器／使用者自行決定是否保存及同步。

localStorage 不是加密保管庫。同源程式、具權限擴充套件、惡意更新／XSS、共用裝置使用者等可能讀取帳號。啟用前請自行評估並承擔本機保存風險；共用或不受信任裝置不建議啟用。這項提醒不是對資料安全的保證，也不表示網站營運者可免除其責任。

## 不能承諾「任何地方都不接手個人資料」

目前路徑是：瀏覽器 → HTTPS/WSS → Cloudflare Pages Worker → HTTPS/WSS → BC。

Cloudflare 是連線中繼，BC 接收帳密、帳號資料及遊戲封包。兩段加密傳輸不等於瀏覽器到 BC 的端對端加密。前端程式本身也必須讀取帳密才能登入。

本次檢查的程式版本：

- Worker 只轉送固定 BC WebSocket，沒有逐封包 callback、帳密／聊天日誌、資料庫或保存 API。
- 前端沒有新增第三方分析追蹤、錯誤回報、聊天上傳或遠端 ECHO 腳本。遊戲連線使用本站資源、relay-status 及同站 Socket.IO；另有使用者許可的外部聊天媒體請求。
- 密碼為自動重連保留於分頁記憶體；登出或重新整理後不再由 Lite 保留。聊天／BEEP 也是記憶體資料。
- 不能由原始碼保證 Cloudflare 的平台處理、部署者的日誌／分析設定、BC 的保存政策、擴充套件行為或未來網站更新。本次未檢查你的 Cloudflare 控制台，也未修改線上部署。

部署者應核對：部署 commit、額外分析／錯誤回報腳本、Worker Observability／日誌／Logpush 等設定，以及其他綁定或中介服務；不要啟用記錄帳密或遊戲封包的程式。不要公開包含帳密／私人訊息的 HAR、WebSocket 封包或除錯輸出。

## ECHO：最小、唯讀的既有外觀保護

目標不是提供衣櫃，而是不讓 Lite 因不認識 ECHO 物品而清除已有外觀。

- 登入收到的 Appearance 和 OnlineSharedSettings 保留原始結構，不做未知物品過濾、重建、壓縮或欄位清洗。
- 一般操作不送 Appearance／OnlineSharedSettings 的 AccountUpdate，也不送角色換裝更新；加／移除好友只送 FriendList。**唯一例外：使用者選擇安全詞操作並確認後，才送 Appearance 與角色外觀更新；「回復」另依 BC 規則收緊 AllowedInteractions／ItemPermission。** 不會改寫 OnlineSharedSettings。
- 房內收到不同外觀不會觸發「覆蓋存檔」或「還原登入外觀」。後者也可能覆蓋其他合法修改，所以不自動還原。
- 不載入完整 ECHO、不發送假版本／能力標籤，也不加入外觀備份雲端服務或本機外觀儲存。

一般操作的目標是不改寫既有外觀，不是保證 ECHO 觀看端的渲染。請先在完整版 BC + ECHO 儲存外觀，登入 Lite 後由另一位裝有 ECHO 的玩家核對。安全詞是明確的改寫例外：回復採本次登入時的快照，解除採目前收到的房內外觀（含單件更新），資料只在分頁記憶體。未知插件欄位在解除時保留，因此不能保證插件束縛全部解除。完整 ECHO 雙向操作不在此範圍內。

## 聊天連結

Lite 現在會向同房玩家發送版本無關的 `Hidden / BCLiteHello` 自報標記，只有 `client: Lite`，不包含帳密、服裝或插件清單；支援的 LCE 可顯示頭頂 Lite 字樣。這代表同房玩家可以辨識你正在使用 Lite，不是匿名客戶端。`window.BCLite` 只提供同頁靜態名稱，不暴露連線操作或個人資料。

原生活動面板可送出 Activity 封包；預設相容模式會略過尚未實作的本機條件，但保留已知禁止偏好及房間限制。接收方完整版 BC 可能依自己的設定產生活動效果。Lite 不執行自身完整自動興奮／表情／道具效果，也不因此新增 Appearance 或 OnlineSharedSettings 寫入。ECHO 等擴展項目僅發送文字，貼貼目前沒有穿戴或位置配對。詳見 [原生活動與識別限制](chat-native-identity-tests.md)。

HTTP(S) 網址以 DOM 文字與連結建立，不解析 HTML。HTTPS 圖片／影片直連須先取得使用者對來源的本次／總是許可才建立內嵌媒體：圖片接近可視範圍時載入，影片預載 metadata、提供播放控制，不自動播放。這些請求直接送往媒體來源，會讓來源收到使用者 IP 等資訊；全站 Referrer-Policy 為 no-referrer。普通網頁與失敗媒體保留連結，另開分頁並設定 noopener／noreferrer。不使用 iframe、外部腳本或預覽 API；這不是惡意網站掃描或安全保證。

「總是許可」只把 HTTPS origin（協定／主機／埠）存於 `bc-lite-media-origins-v1`；本次許可存在記憶體，重新整理或登出後清除。設定頁可撤銷兩種許可，不能撤回已送出的請求；許可來源的重新導向由瀏覽器處理。私聊歷史、AFC 房間資訊與召喚允許名單只保留在本次分頁記憶體，不新增雲端保存或插件資料上傳。

## 驗收

1. 不勾選記住帳號登入，localStorage 不應新增帳號 key。
2. 勾選後登入、登出／重新整理：帳號預填，密碼不由 Lite 預填。若瀏覽器自動填密碼，需另檢查瀏覽器密碼管理器。
3. 取消勾選或設定頁刪除後重新整理：不應從 Lite 保存資料預填帳號。
4. Application → Local Storage 只應有顯示偏好、選擇保存的帳號及選擇記住的媒體來源，不能出現密碼、外觀或聊天。
5. 已裝 ECHO 的觀看者比對 Lite 登入前後外觀，測加好友與聊天後再返回完整版核對。不可把自動測試通過當成真實 ECHO 外觀驗收。
